Что мы на самом деле про вас знаем — за полгода эксплуатации

  1. LOG‑01

    Провижининг

    Бокс поднимается за 55 секунд — засекали секундомером, а не отделом маркетинга.

  2. LOG‑02

    Диски

    Только NVMe. Последний HDD выкатили из парка ещё в 2023-м, менять не планируем.

  3. LOG‑03

    Сеть

    Фильтр L3/L4 стоит перед каждым портом по умолчанию. Отключить нельзя, доплачивать не нужно.

  4. LOG‑04

    Бэкапы

    Снапшот руками — один клик. Автобэкап — раз в сутки, 7 копий, без квоты сверху тарифа.

  5. LOG‑05

    Доступ

    Чистый root, голый iptables. Никакой предустановленной телеметрии от нас на борту.

  6. LOG‑06

    Апгрейд

    CPU, RAM и диск меняются без переустановки. Простой — секунд 20, не часы ожидания.

Нужна своя конфигурация? Собирается вручную в панели — CPU, RAM и диск отдельными ползунками.

// протокол выдачи

Три команды между оплатой и root@

01$ boxes choose --plan=B2 --location=fra

→ бокс зарезервирован, ждёт оплаты

02$ boxes pay --method=card|sbp|crypto

→ платёж принят, старт провижининга

03$ boxes receive --to=panel,email

→ IP, root-пароль и SSH-ключ — за ~60 секунд

Вопросы, которые задают до, а не после оплаты

$ grep -i
Q> Как быстро бокс будет готов после оплаты?
A> Обычно 55 секунд. Иногда 40, иногда 70 — зависит от очереди на ноде, а не от того, пятница сегодня или нет.
Q> Можно сменить тариф после покупки?
A> Да. Апгрейд и даунгрейд CPU, RAM и диска — прямо в панели, простой около 20 секунд, диск не переразмечивается заново.
Q> Какие способы оплаты поддерживаются?
A> Карта, СБП, крипта (USDT, BTC, ETH). Юрлицам — счёт по безналичному расчёту.
Q> Есть возврат, если бокс не подошёл?
A> 3 дня с момента первой оплаты — возвращаем без выяснений «а что конкретно не так».
Q> Какие операционные системы доступны?
A> Ubuntu, Debian, CentOS, AlmaLinux, Windows Server — плюс образы с Docker и панелями, для тех, кто панели любит.
