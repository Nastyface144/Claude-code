# NVX / CODE — приветственные тексты

Заготовки для описания канала и закреплённого поста. Подставь имя, ник и ссылку на чат.

## Описание канала

Лимит Telegram — 255 символов, без разворота видно первые две строки.

```
Пишу код и показываю процесс изнутри — без успешного успеха.
Проекты, инструменты, факапы.

💬 Чат: t.me/nvx_code_chat
✉️ Связь: @твой_ник
```

## Закреплённый пост — основной вариант

```
>_ NVX / CODE

Привет. Я <имя>, разработчик. Пишу код каждый день
и показываю процесс — не только то, что получилось,
но и то, что развалилось по дороге.

Что здесь будет:

#code — что делаю прямо сейчас, куски кода, решения
#tools — инструменты, которые реально экономят время
#fail — факапы и что я из них вынес
#til — что узнал за день
#life — жизнь программиста вне редактора

Чего здесь не будет: курсов, инфоцыганства
и «войти в IT за три месяца».

💬 Обсудить: t.me/nvx_code_chat
✉️ Написать мне: @твой_ник
```

## Закреплённый пост — терминальный вариант

```
$ whoami
nvx — разработчик, пишу код и показываю как

$ ls ./channel
code/   tools/   fail/   til/   life/

$ cat ./rules.txt
без курсов, без инфоцыганства,
без «войти в IT за 3 месяца»

$ echo $CONTACTS
chat  → t.me/nvx_code_chat
admin → @твой_ник

$ _
```

## Чек-лист приветствия

- [ ] Хештеги-рубрики перечислены в закрепе — в Telegram они кликабельны и работают как навигация
- [ ] Есть строка «чего здесь не будет» — отсеивает не свою аудиторию
- [ ] Ссылка на чат отдельной строкой, а не только привязанные комментарии
- [ ] Оставлено место под блок «начни отсюда» с тремя ссылками (заполнить через месяц)
- [ ] Заведена категория историй «О канале» с обложкой-визиткой
- [ ] В конце — вопрос в чат, а не «подписывайся»
