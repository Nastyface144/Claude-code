# NVX / CODE — фирменный стиль канала

Все ассеты собираются из кода: `brand/build.py` пишет SVG в `brand/svg` и рендерит PNG в `brand/png`.

```bash
pip install cairosvg
python3 brand/build.py
```

## Палитра

| Роль | HEX |
|---|---|
| Акцент (светлый) | `#9B6BFF` |
| Основной | `#6D3BE8` |
| Глубокая тень градиента | `#2A1467` |
| Фон обложек | `#07080B` |
| Вторичный текст | `#8A8FA0` |

Шрифты в сборке — DejaVu Sans / DejaVu Sans Mono, они есть в любой Linux-системе.
Для «боевой» версии замени на Inter (заголовки) и JetBrains Mono (код) — правь константы
`SANS` и `MONO` в `build.py`.

## Ассеты

| Файл | Размер | Куда |
|---|---|---|
| `avatar-a-prompt.png` | 512×512 | аватар канала, вариант `>_` |
| `avatar-b-branch.png` | 512×512 | аватар канала, вариант «ветка git» |
| `avatar-c-wordmark.png` | 512×512 | аватар канала, текстовый логотип |
| `cover-headline.png` | 1080×1920 | шаблон истории с крупным заголовком |
| `cover-code.png` | 1080×1920 | шаблон истории с карточкой кода |

Аватар Telegram обрезает в круг: вся значимая графика держится внутри радиуса 243 px.
Обложки историй свёрстаны в колонке 72..1008 px, сверху ~220 px занимает шапка Telegram,
снизу ~320 px — панель ответа. В эти зоны текст не заходит.

## Как менять текст обложек

Тексты лежат прямо в константах `COVER_HEADLINE` и `COVER_CODE` в `build.py` — меняешь строку,
запускаешь скрипт, получаешь новый PNG. Строки заголовка не переносятся автоматически:
держи до ~13 заглавных символов в строке при кегле 118 и до ~15 при кегле 92.
